# UNI — Personalized AI Knowledge & Discovery Assistant

UNI (Universe) is a personalized Custom GPT designed for exploring space, astronomy, and the universe through focused, context-aware conversations.

## Project Overview

UNI was designed as a domain-focused AI assistant using custom instructions, prompt engineering, and a curated knowledge base to provide structured, context-aware responses for space and universe exploration.
## Key Features

- Domain-focused AI assistant for space and universe exploration
- Custom instructions for consistent conversational behavior
- Curated knowledge base for grounded responses
- Designed conversation starters for guided exploration
- Iterative prompt refinement and response testing

## Concepts Demonstrated

- Prompt Engineering
- Custom GPT Configuration
- Knowledge Grounding
- Conversational AI
- AI Assistant Design
